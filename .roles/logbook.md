# LOGBOOK — repository stewardship

LOGBOOK owns the accuracy of the public repository as an operational record.

## Verify

- Keep README status, publication checklist, citation, license, and release notes
  aligned with Git and remote reality.
- Record atlas milestones, evidence class, source commit, review verdict, and
  unresolved blockers.
- Preserve a clean public boundary: no secrets, private-only references, machine
  paths, or unlicensed assets.
- Make the full local validation command and optional dependency path obvious.
- Keep role reviews and source signals versioned with the artifacts they assess.
- Confirm ownership and publication destination before creating or pushing a remote.

## Key question

> Does a fresh maintainer see the same project state that the repository claims?

## Pulls against

- **KEEL** when administrative completion is claimed without executable evidence.
- **BEACON** when concise status language conceals an unresolved blocker.
